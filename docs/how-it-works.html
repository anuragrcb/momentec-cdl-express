Design upload, end to end

One photo in. Four views of a real Momentec style. A proof PDF in private storage. The customer leaves after Upload. They do not wait for the PDF.

1Website

In
One design photo (jpg, png, or webp), plus category and gender. Size, name, and email stay locked until the four views exist. The photo is masked at 512 px, then that mask is applied to the original and flattened on white at up to 1536 px.
Prompt or call
None. Make the four views stays disabled until category and gender are set. Changing either after the views exist clears those views.
Out
The flattened photo, category, and gender, forwarded.
Example
A short-sleeve crew jersey photo with a chest wordmark and a number.

2OpenAI, first call

In
The uploaded photo.
Prompt or call
DESCRIBE_PROMPT. It lists the catalog’s real product names (Crew Neck Baseball Jersey, Traditional Track Jersey, Basketball Shorts, and so on) and asks for JSON only. A one-piece singlet, dress, or similar cut must come back as not supported.
Out
JSON: supported, up to three catalog queries, sleeve cut, segment, visible logo places, visible text places, button flag, color-panel count.
Example, reject
{
  "supported": false,
  "unsupported_reason": "Momentec does not manufacture one-piece wrestling singlets."
}
Example, pass
{
  "supported": true,
  "queries": ["Turbo Training Tee", "Crew Neck Baseball Jersey", "Volleyball Tee"],
  "garment_piece": "top",
  "sleeves": "short",
  "segment": "adult",
  "logo_locations": ["Front Center Full"],
  "text_locations": ["Front Center"],
  "has_buttons": false,
  "color_panels": 1
}

Stop

When
supported is false.
Out
The page shows the reason. No catalog search, no Magnific call, no PDF.

3Catalog search

In
Each query from step 2. Products only. Optional sport and adult / youth / ladies filter from the form.
Prompt or call
POST /search
{
  "query": "Crew Neck Baseball Jersey",
  "top_k": 12,
  "collections": ["products"],
  "group_products_by_style": true
}
Out
Ranked styles. Each row has style, name, brand, sport, segment, score, logo_locations (code + name), text_locations (code, name, allowed inch heights), color_zones.
Example
{
  "style": "228137",
  "name": "FreeStyle Sublimated Turbo Crew Neck Baseball Jersey",
  "brand": "Holloway",
  "sport": "BASEBALL",
  "text_locations": [{ "code": "t2", "name": "Front Center", "params": ["2", "4"] }],
  "color_zones": [{ "code": "SUB_FIRST_BODY_COLOR", "name": "Body Color" }]
}

5OpenAI, second call + catalog placement filter & color snap

In
Image 1 is the customer photo. Then up to three 2x2 candidate sheets, each labeled with that style’s name, brand, allowed logo_locations, allowed text_locations, and color_zones.
Prompt or call
1. JUDGE_AND_PLAN_PROMPT: pick the style whose cut matches (or set supported: false). Map the upload onto only the winning style’s allowed color_zones, logo_locations, and text_locations, with a 6-digit #RRGGBB hex code on every color. Any logo, wordmark, or number sitting on a placement the winning style does not support is omitted.
2. filterPlanToAllowedCatalog: strips any entry in colorZoneMapping, logoMapping, or textMapping that does not match an active catalog code or name on the winning style.
3. snapPlanColors → POST /colors/nearest (with local CIE Lab ΔE fallback over the 173 Momentec brand colors): snaps every #RRGGBB hex in the plan to the closest solid Momentec color for the winning style’s brand (skipping tonal/camo chips) and rewrites the plan with official Momentec color names and hex codes.
Out
Winning style (or a 422 rejection), plus color_zone_mapping, logo_mapping, text_mapping, and view_plan restricted to supported catalog locations and snapped to official Momentec brand colors.
Example
{
  "supported": true,
  "style": "228137",
  "color_zone_mapping": [
    "Body Color (SUB_FIRST_BODY_COLOR): PURPLE (#2A0A5F)",
    "Accent 1 (SUB_FIRST_ACCENT_1): SCARLET (#A31F2D)"
  ],
  "logo_mapping": [
    "Upper Left Chest (m6): shield crest in WHITE (#FFFFFF) and SCARLET (#A31F2D) on front view"
  ],
  "text_mapping": [
    "Front Center (t2): TIGERS in BRIGHT YELLOW (#FFF327) outlined in BLACK (#000000)",
    "Front Center (t2): 24 in BRIGHT YELLOW (#FFF327) under the word"
  ],
  "view_plan": {
    "front": "PURPLE (#2A0A5F) body with SCARLET (#A31F2D) accents, m6 chest crest, and t2 TIGERS / 24.",
    "back": "PURPLE (#2A0A5F) body. Leave back clean.",
    "left": "PURPLE (#2A0A5F) sleeve and SCARLET (#A31F2D) side panel. Omit unsupported sleeve patch.",
    "right": "PURPLE (#2A0A5F) sleeve and SCARLET (#A31F2D) side panel."
  }
}

6Magnific

In
Image 1: the winning style’s 2x2 template. Image 2: the customer photo. The prompt includes the filtered placements and snapped Momentec color mappings from step 5. A later “Apply this edit” sends the same template again as Image 1, with the edit note added as one line. It does not redraw a new garment.
Prompt or call
buildCatalogProjectionPrompt → Magnific gpt-image-2-edit. Keep Image 1’s exact 3D silhouette, collar, sleeves, buttons, hem, and 2x2 layout. Paint every fabric zone, trim, logo, and text using the snapped Momentec #RRGGBB hex codes instead of copying raw shades from Image 2. Render only the logos and text/numbers listed in the allowed catalog placements; any mark on Image 2 at an unsupported placement is left blank. If the judge’s confidence is below 0.6, or the winner is not one of the candidate styles, the page stops and asks for an artist review. Magnific is not called.
Out
One 2x2 PNG rendered in the closest manufacturable Momentec colors and allowed placements. The site splits it on the white cross into front, back, left, and right, and shows those four views to the customer.
Example
A V-neck template comes back as four views of that exact cut, painted in the snapped Momentec brand hexes, with only the catalog-supported front chest markings applied.

7Upload

In
The finished 2x2 sheet, customer name, email, sport, gender, size, optional comment, and the matched catalog payload (style, brand, logo_locations, text_locations, color_zones, and the snapped plan).
Prompt or call
Write <jobId>/sheet.png and <jobId>/job.json to S3, then invoke momentec-cdl-proof asynchronously (InvocationType: "Event"). The HTTP request returns 202 Accepted immediately.
Out
A job id. The page confirms the upload and the customer can close the modal.
Example
{ "jobId": "859ce71d-29cb-42d4-a57d-fc70b7a198fb" }

8Proof job (AWS Lambda)

In
<jobId>/sheet.png and <jobId>/job.json (gender, size, and the matched style’s brand, logo_locations, text_locations, color_zones, and snapped plan).
Prompt or call
OpenAI (DECORATION_LIST_PROMPT, JSON schema, temperature 0, one retry) reads the sheet against the style’s official catalog zones and locations. Code drops any fill zone or decoration mark that is not in the style’s allowed color_zones, logo_locations, or text_locations, snaps mark heights to the location’s allowed inch params, and snaps every fill and ink hex to the official Momentec brand color (POST /colors/nearest with local CIE Lab ΔE fallback). The front and back pictures are cropped from the approved sheet. Magnific isolates each allowed mark on white.
Out
A private PDF at <jobId>/proof.pdf in S3. Page 1: order summary, cropped front and back, the matched style number, garment name, and real size, plus snapped fill colors. Next: team/company decoration and roster decoration. Last: the customer’s name and message. REF#, ecom order number, and artist stay highlighted because they still have no source.
Example
FILL COLORS
BODY COLOR: SCARLET
ACCENT 1: ROYAL

TEAM/COMPANY DECORATION
FRONT CENTER FULL SUBLIMATION
LOC: M2
ART HEIGHT: 4.1 INCH    ART WIDTH: 7 INCH

ROSTER DECORATION
BACK CENTER SUBLIMATION NUMBER
LOC: T7
SENTINEL: 8 INCH

REF#, the ecom order number, and the artist stay the sample values. The style number, garment name, size, and customer comment come from the job.
